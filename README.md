# Stepper

A simple multi-step progress indicator built with HTML, CSS, and JavaScript.

## Features

- Four checkout steps:
  - Contact Details
  - Shipping Address
  - Payment
  - Delivered
- Next and Previous navigation
- Active step highlighted in blue
- Completed steps shown in green with checkmarks
- Progress line updates as steps are completed
- Finish state after the final step

## Run locally

1. Clone or download the repository.
2. Open `index.html` in a browser.

For the best development experience, open the project in VS Code and use a local server extension such as Live Server.

## Project files

| File | Purpose |
| --- | --- |
| `index.html` | Defines the stepper structure |
| `style.css` | Provides the layout and visual styling |
| `script.js` | Handles navigation and step state changes |
